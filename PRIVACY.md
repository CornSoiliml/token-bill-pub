Privacy Policy
Token Bill does not collect, transmit, or store any user data on the developer's servers.
Data stored locally. The extension saves the following only on the user's device via chrome.storage.local:
- The Grafana instance URL the user enters
- The Grafana username and password the user enters
- The API key(s) the user chooses to monitor
- Settings such as refresh interval and theme preference
- A cache of the most recently fetched monitoring data
How data is used. The stored credentials are sent only to the user's own configured Grafana instance (via HTTPS Basic Auth) to read monitoring data such as API token spend, quota, and token usage. This data is used solely to display the information in the extension's toolbar badge and popup.
No third-party sharing. The extension does not transmit any data to the developer or any third party. It contains no analytics, tracking, or advertising SDKs.
Data retention. All data remains on the user's device and is deleted when the user clears the extension's data or uninstalls the extension.
Contact. For any questions about this privacy policy, please contact the extension's administrator within your organization.
